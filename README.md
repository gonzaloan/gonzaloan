## The Ship-It Scorecard

Five questions I use to review AI systems:

| Gate | Question |
| --- | --- |
| **Secure** | Are data, permissions, and untrusted inputs handled safely? |
| **Provable** | Can evaluations demonstrate that it works? |
| **Observable** | Can we understand its behavior and investigate failures? |
| **Cost-bounded** | Are spending limits and cost per run understood? |
| **Governed** | Are ownership, audit trails, and human approvals clear? |
